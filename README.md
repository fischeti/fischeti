## Hi, I'm Tim 👋

Hardware engineer in Zurich, working on on-chip networks, RISC-V many-core systems, and the tooling around them.
PhD from ETH Zürich ([IIS](https://iis.ee.ethz.ch/) / [PULP Platform](https://pulp-platform.org/)), now at Tenstorrent.

I like building **developer tools for hardware engineers**: the kind of tooling software people take for granted, but which RTL designers still rarely have.

### 🔌 Hardware

- [**FlooNoC**](https://github.com/pulp-platform/FlooNoC): a fast, low-overhead AXI-compatible network-on-chip. I'm the main author.
- [**Snitch cluster**](https://github.com/pulp-platform/snitch_cluster): an energy-efficient RISC-V floating-point compute cluster.
- [**Picobello**](https://github.com/pulp-platform/picobello): a multi-cluster Snitch system connected by FlooNoC.

### 🛠️ Tooling

- [**astli**](https://github.com/fischeti/astli): SystemVerilog language tooling (formatter & more), written in Rust. Also available as a [GitHub Action](https://github.com/fischeti/astli-action) and a [pre-commit hook](https://github.com/fischeti/astli-pre-commit).
- [**rdlfmt**](https://github.com/fischeti/rdlfmt): an opinionated formatter for SystemRDL register descriptions.
- [**PeakRDL-rawheader**](https://github.com/pulp-platform/PeakRDL-rawheader): a PeakRDL plugin that generates plain C headers from SystemRDL register maps.
- [**Bender**](https://github.com/pulp-platform/bender): a dependency manager for hardware projects, written in Rust.
- [**iis-typst**](https://github.com/pulp-platform/iis-typst): all of IIS's LaTeX templates (thesis, slides, reports, …), rebuilt in Typst.
